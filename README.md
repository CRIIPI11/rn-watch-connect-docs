# rn-watch-connect docs

The documentation site for [`rn-watch-connect`](https://github.com/CRIIPI11/rn-watch-connect), built with [Fumadocs](https://fumadocs.dev) on Next.js.

```bash
npm install
npm run dev
```

Open http://localhost:3000. Pages live in `content/docs/`.

What the site covers, and why, is in [`DECISIONS.md`](DECISIONS.md). The build steps are in [`PLAN.md`](PLAN.md).
